# Design & UI/UX Skills

Project-level Claude Code skills for building high-quality UI/UX.

Source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT, author: claudekit / NextLevelBuilder)

Included skills:
- **ui-ux-pro-max** — Core design intelligence: 50+ styles, 161 palettes, 57 font pairings, 99 UX guidelines, 25 chart types across 10 stacks.
- **ui-styling** — shadcn/ui + Tailwind components, accessible layouts, dark mode.
- **design** — Brand identity, logos, design tokens, banners, icons, social images.
- **design-system** — Token architecture (primitive→semantic→component), component specs.
- **brand** — Brand voice, visual identity, messaging frameworks.
- **banner-design** — Social/ad/web/print banners.
- **slides** — HTML presentations with Chart.js.

These load automatically for this project. Invoke via the Skill tool or `/ui-ux-pro-max` etc.
