Comment ça marche

Trois étapes, aucune installation côté client.

1

On équipe vos tables

Nous posons une puce NFC élégante (ou un support design) sur chaque table, reliée à votre menu personnalisé.

2

Le client tape

Il approche son téléphone de la puce. Le menu s'ouvre dans le navigateur — pas d'appli, pas de QR code à viser dans le noir.

3

Vous gérez tout

Prix, plats, photos, ruptures de stock : vous modifiez votre menu en temps réel depuis un simple tableau de bord.
